# Build Spotlight music discovery app

## What will be built
- Replace the placeholder with the mobile-first Spotlight home screen from the supplied references.
- Add connected Categories, Discover, and Musician Profile screens using the supplied copy and imagery.
- Recreate the persistent header, bottom navigation, compact audio player, music cards, filters, statistics, and profile actions.
- Make primary navigation and playback/favorite controls interactive, with layouts that also adapt cleanly to desktop widths.

## Visual direction
- Match the references’ dark studio aesthetic, amber primary actions, cyan and violet category accents, condensed labels, and atmospheric artist photography.
- Preserve the supplied Portuguese interface copy and imagery.

## Technical details
- Use TanStack Router route files for `/`, `/categories`, `/discover`, and `/musician/helena-duarte`.
- Build shared navigation and audio-player elements as reusable React components.
- Define semantic color, typography, shadow, and animation tokens in the global design system.
- Add unique page metadata for every content route.
- Verify key navigation and controls at phone and desktop viewport sizes.
